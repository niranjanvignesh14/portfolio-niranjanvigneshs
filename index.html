Enterprise Financial Data Investigator

Multi-agent analytics mesh · Final-year capstone & interview showcase project

A stateful, cyclic multi-agent system built in LangGraph for investigating financial data — designed with the token budgets, retry limits, and audit trail a production analytics tool actually needs, not just a demo.

Orchestration

Cyclic multi-agent graph in LangGraph, token budget caps, max-3-retries kill-switch

Tool isolation

Decoupled Python MCP server separating DB schemas and tools from the LLM core
